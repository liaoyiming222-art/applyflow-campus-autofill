# 歌尔简历表单字段矩阵

数据来源：2026-08-20 在歌尔校招当前空白简历模板中读取的真实 DOM。当前模板与旧截图会有差异，因此民族、籍贯等历史字段也保留为兼容用例。

| 区块 | 字段 | 控件与填写方式 | MVP处理 |
|---|---|---|---|
| 应聘信息 | 招聘信息来源、毕业年份 | Ant 单选下拉；打开弹层后按显示文本选择并校验回显 | 自动 |
| 个人信息 | 姓名、电话、邮箱、微信ID、身高、体重 | React 受控文本框；原生 value setter + input/change | 自动 |
| 个人信息 | 性别 | 单选组；根据选项文字点击并检查 checked | 自动 |
| 个人信息 | 国籍、政治面貌、婚姻状况 | Ant 单选下拉 | 自动 |
| 个人信息 | 出生日期 | Ant 日期面板；依次选择年、月、日并检查输入框回显 | 自动 |
| 兼容字段 | 民族 | Ant 单选下拉 | 自动 |
| 兼容字段 | 籍贯 | Ant TreeSelect；按省→市逐级展开并检查最终路径 | 自动 |
| 求职意向 | 第一、第二、第三工作意向地 | 三个独立 Ant 下拉；按档案城市顺序逐个填写 | 自动 |
| 求职意向 | 是否调剂、是否接受潍坊 | 单选组，但属于用户临场决策 | 手动 |
| 求职意向 | 期望薪酬 | React 受控文本框 | 自动 |
| 教育经历 | 开始/结束时间 | Ant 年月面板 | 自动、多段 |
| 教育经历 | 学校、学历类型、学历、学位、一级学科 | 可搜索 Ant 下拉；按选项显示文本选择 | 自动、多段 |
| 教育经历 | 校区、院系、专业、课程、GPA、实验室、方向、导师 | 文本框或文本域 | 自动、多段 |
| 教育经历 | 海外院校、排名、最高学历、学生干部 | 安全枚举单选组 | 自动、多段 |
| 实习经历 | 企业、职位、开始/结束时间、工作描述 | 文本、年月、文本域；先新增到档案段数 | 自动、多段 |
| 工作经历 | 企业、职位、开始/结束时间、工作描述 | 仅使用独立 `work[]` 档案；档案有记录才新增和填写 | 自动、多段、可选 |
| 项目经验 | 项目名称、项目职务、开始/结束时间、项目描述 | 文本、年月、文本域；先新增到档案段数 | 自动、多段 |
| 外语水平 | 语言、语言等级、成绩 | 语言与等级分别使用 Ant 下拉；档案不保存考试类型 | 自动、多段 |
| 奖励荣誉 | 奖励级别、名称、日期、描述 | 国家级映射“国家级及以上”，省/校/赛区级映射“其他” | 自动、多段 |
| 科研成果 | 当前档案模型尚无对应结构化数据 | 页面可新增，但本 MVP 不从其他经历推断 | 手动 |
| 家庭关系 | 是否有亲属、关系及亲属信息 | 隐私及用户决策字段 | 手动 |
| 其他技能 | 其他技能 | React 受控文本框 | 自动 |
| 照片、附件、隐私同意、保存 | 文件、复选框、提交按钮 | 涉及上传或提交 | 手动 |

## 验收口径

1. “成功”必须同时满足：找到字段、取得档案值、网站控件产生可读回显。
2. 重复经历必须先把页面记录数扩展到档案记录数，再重新扫描和逐段填写。
3. 一个失败的下拉弹层不能影响后续控件类型判断；控件类型必须由当前字段确定。
4. 插件不得点击保存、隐私同意或提交申请。
5. “工作经历”与“实习经历”必须属于不同区块和不同数组；只有 `work[]` 非空时才新增、填写工作经历，不得使用 `experience[]` 数据代替。
