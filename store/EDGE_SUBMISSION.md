## 单一用途说明

ApplyFlow 帮助校招求职者在招聘网站中识别并填写姓名、联系方式、教育经历、实习经历、项目经历等通用简历字段。证件等个人字段只有在用户已明确保存且主动点击填写时才会使用；公司特有和主观问题由用户自行完成，扩展不会自动提交招聘申请。

## 权限说明

### activeTab

用户点击扩展工具栏图标后，临时访问当前招聘表单页面。扩展不会在用户未操作时读取其他标签页。

### scripting

用于在当前页面注入本地打包的字段识别和填写脚本。扩展不下载或执行远程代码。

### storage

用于在 Microsoft Edge 本地保存用户主动录入的求职档案、填写数量和预计节省时间。

### sidePanel

用于在 Microsoft Edge 侧边栏展示识别结果、填写按钮和需要用户自行处理的字段数量。

## 远程代码声明

## 中文商店长描述

ApplyFlow 是一款面向校招和实习求职者的 Microsoft Edge 智能填表扩展。用户可以在浏览器本地维护一份求职档案；进入招聘网站后，点击扩展图标即可识别姓名、手机号、邮箱、学校、专业、学历、教育时间、实习经历和项目经历等通用字段，并由用户主动执行填写。

扩展坚持“重复信息交给插件，重要选择留给自己”。公司特有问题、开放性问题和主观求职选择不会被擅自推断；证件等个人字段只使用用户已保存的明确值。扩展不会自动提交申请。填写完成后，扩展会列出仍需用户处理的项目，并根据成功填写的字段类型保守估算本次节省时间。

当前版本不接入 AI，不连接开发者服务器，不自动投递职位。求职档案和使用统计默认保存在 Microsoft Edge 扩展本地存储中。扩展只在用户点击工具栏图标后临时访问当前页面，并且只申请实现核心功能所必需的权限。

### 主要功能

- 本地维护基本信息、教育经历、实习经历、工作经历、项目经历、外语能力、奖励荣誉和求职偏好；
- 识别常见招聘表单中的文本框、下拉框、日期、单选项和多段经历；
- 由用户主动点击后填写明确匹配的通用字段；
- 展示已填写字段、仍需处理的项目及预计节省时间；
- 不推断主观问题，不点击保存或提交申请。

### 使用提示

不同招聘网站的表单实现存在差异。请在正式提交申请前检查自动填写结果，并手动完成公司特有问题、开放性问题、附件、验证码及隐私确认。

## 审核测试步骤

1. 在 Microsoft Edge 中加载扩展包，并在扩展详情中允许访问文件 URL（仅测试本地示例页时需要）。
2. 打开扩展的“我的档案”页面，录入姓名、手机号、邮箱及一段教育经历并保存。
3. 打开扩展包内 `tests/sample-form.html` 对应的测试页面，或者打开任意包含招聘表单的 HTTPS 页面。
4. 点击工具栏中的 ApplyFlow 图标，确认页面右侧出现悬浮球。
5. 点击悬浮球，在 Edge 侧边栏中查看识别结果并点击“填写通用字段”。
6. 验证通用字段被填写、开放性问题未被填写、网页提交按钮未被触发。

## 给审核团队的说明

ApplyFlow 的单一用途是帮助校招及实习求职者重复填写招聘网站中的通用简历字段。扩展不会搜索职位、不会代替用户投递，也不会点击招聘网站的保存或提交按钮。

扩展仅在用户点击工具栏图标后对当前标签页启用。随后页面显示 ApplyFlow 悬浮球；用户点击悬浮球后打开 Edge 侧边栏，并主动点击“智能填写字段”才会执行填写。点击 Edge 侧边栏原生关闭按钮会关闭当前页面助手。

用户档案保存在 `chrome.storage.local`。当前版本不接入 AI，不连接开发者服务器，不加载远程代码，也不向开发者或第三方传输档案。扩展写入招聘网站表单的内容完全来自用户在“我的档案”中明确保存的数据。证件等敏感字段仅在用户已录入相应值且主动执行填写时使用。

为方便审核，可使用扩展包中的 `tests/sample-form.html`。在 Edge 扩展详情页开启“允许访问文件 URL”后打开该文件，按“审核测试步骤”操作即可验证字段识别和填写。测试页不需要登录、网络接口或真实个人资料。

预期结果：姓名、手机号、邮箱、学校等通用字段被填写；开放性问题保持不变；页面的保存或提交按钮不会被触发。
