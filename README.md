# ApplyFlow 校招填表助手 MVP

一个不接入 AI、以 Microsoft Edge 为主要发布平台的 Manifest V3 浏览器插件。它只处理招聘官网中明确、通用、重复的简历字段；证件等个人字段仅在用户已保存明确值并主动点击填写时使用，公司特有和主观问题仍由用户自行填写。由于 Edge 基于 Chromium，当前代码也尽量保持与 Chrome 兼容。

> 当前源码版本：0.7.6。项目仍处于 MVP 阶段，请在正式投递前检查所有自动填写结果。

## 当前能力

- 本地维护基本信息、证件与个人属性、教育、实习、工作、项目、外语、奖励、技能和求职偏好
- DOCX/TXT 简历本地解析并自动保存到档案，以及 JSON 档案导入、导出
- 用户点击插件图标后，仅在当前页面启用
- 识别常见中英文字段别名，并严格隔离教育、实习、工作、项目、外语和奖励区块
- 填写文本框、文本区域、原生/常见 Ant Design 下拉框、TreeSelect、Cascader、日期和明确单选项
- Ant Design 日期字段采用事件写入与日历面板点击两级回退，并在填写后回读确认
- 毕业年份可从毕业日期派生；档案中没有值时不自动猜测
- 填写前可按档案数量补齐教育、实习、项目、外语和奖励记录，等待页面生成新表单后再逐段匹配
- 标记已填写和仍需处理的字段
- 求职意向分别维护第一、第二、第三期望城市，并对应填写三个工作意向地
- 估算本次及累计节省时间
- 不自动提交申请

## 在 Microsoft Edge 中安装体验

1. 在 Microsoft Edge 地址栏打开 `edge://extensions/`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择本项目目录。
4. 在普通 HTTP/HTTPS 招聘页面点击插件图标，页面右侧会出现悬浮球。
5. 点击悬浮球打开 Microsoft Edge 侧边栏。
6. 从侧边栏进入“我的档案”，可手动录入或解析 DOCX/TXT 简历。

如果使用项目内的本地 HTML 测试页，需要在扩展详情页打开“允许访问文件 URL”。`edge://` 浏览器内部页面禁止注入扩展，不能显示悬浮球。

## 开发与测试

```powershell
npm install
npm test
```

浏览器回归默认调用本机 Microsoft Edge。也可以通过环境变量 `APPLYFLOW_BROWSER_CHANNEL` 指定 Playwright 支持的其他 Chromium 浏览器通道。

用于测试的姓名、手机号、邮箱、证件号码和经历均为虚构数据，不得用于真实申请。

`tests/虚构测试简历-林晨曦.docx` 用于验证没有工作经历时的跳过逻辑；`tests/虚构测试简历-林晨曦_新增工作经历.docx` 是包含两段独立工作经历的完整解析样例。

## MVP 边界

- 支持结构清晰、带章节及字段标签的 DOCX/TXT；复杂自由排版简历和 PDF 暂不支持。
- 已支持带有明确“新增教育/实习/工作/项目/外语/奖励”入口的网站按档案数量自动补齐多段记录；工作经历使用独立档案数据，档案无工作记录时完全跳过，绝不会用实习数据推断；按钮文案或交互高度定制的网站仍需手动新增后重新识别。
- 已覆盖常见 Ant Design 下拉和日期输入；其他网站的高度定制组件仍可能需要手动处理。
- 家庭关系、是否调剂、特定城市接受度、附件上传、验证码、开放性问题和自动提交不在自动填写范围内。
- 档案保存在 `chrome.storage.local`，不上传服务器。

## 发布到 Microsoft Edge Add-ons

1. 完成 Edge 中的真实页面兼容测试。
2. 在 `PRIVACY.md` 补充开发者联系方式并发布为公开网页。
3. 准备扩展 Logo、商店截图和支持链接。
4. 运行 `scripts/package-edge.ps1` 生成商店上传 ZIP。
5. 通过 Microsoft Partner Center 创建扩展并上传 ZIP。

商店描述、权限理由、数据声明和审核步骤见 `store/EDGE_SUBMISSION.md`。

## 目录

```text

background.js              当前页面启用与侧边栏控制
shared/schema.js           标准字段、别名和时间估算规则
content/                   页面识别、填写及悬浮球
sidepanel/                 当前页面助手界面
profile/                   本地求职档案编辑器
```
